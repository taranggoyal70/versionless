| Skill role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for autonomous work |
| `ready-for-human` | `ready-for-human` | Requires human judgment or access |
| `wontfix` | `wontfix` | Will not be implemented |
